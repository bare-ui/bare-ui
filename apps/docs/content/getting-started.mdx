# Getting Started

## Installation

<Steps>

### Install the package

<ForReact>
```bash npm2yarn
npm install @wire-ui/react
```

Wire UI has no production dependencies. React is a peer dependency.
</ForReact>
<ForVue>
```bash npm2yarn
npm install @wire-ui/vue
```

Wire UI has no production dependencies. Vue is a peer dependency.
</ForVue>
<ForSolid>
🚧 Solid JS support is coming soon.
</ForSolid>

### Add peer dependencies

<ForReact>
If you don't already have React:

```bash npm2yarn
npm install react@^19 react-dom@^19
```
</ForReact>
<ForVue>
If you don't already have Vue:

```bash npm2yarn
npm install vue@^3.5
```
</ForVue>
<ForSolid>
🚧 Solid JS support is coming soon.
</ForSolid>

<ForReact>

## Styling approach

Wire UI ships no CSS. All interactive state is exposed through `data-*` attributes. Target them with any CSS approach you prefer.

## Compound components

Complex components use a compound pattern. You compose the markup yourself:

<ForReact>
```tsx
import { Input } from '@wire-ui/react'

<Input.Root value={value} onChange={setValue}>
  <Input.Label>Email address</Input.Label>
  <Input.Field type="email" placeholder="you@example.com" />
  <Input.Error />
</Input.Root>
```
</ForReact>
<ForVue>
```vue
<script setup>
import { ref } from 'vue'
import { InputRoot, InputField, InputLabel, InputError } from '@wire-ui/vue'

const value = ref('')
</script>

<template>
  <InputRoot v-model="value">
    <InputLabel>Email address</InputLabel>
    <InputField type="email" placeholder="you@example.com" />
    <InputError />
  </InputRoot>
</template>
```
</ForVue>
<ForSolid>
🚧 Solid JS support is coming soon.
</ForSolid>

You control the DOM order. Need the error above the field? Swap them. Need a wrapper div between label and field? Add it. Wire UI never dictates structure.

## Validation pattern

Wire UI components do **not** validate internally. You own validation — set `invalidType` when your logic determines the field is invalid:

<ForReact>
```tsx
const [email, setEmail] = useState('')
const [invalidType, setInvalidType] = useState('')

function handleSubmit(e: React.FormEvent) {
  e.preventDefault()
  if (!email) setInvalidType('required')
  else if (!email.includes('@')) setInvalidType('email')
  else setInvalidType('')  // clear the error
}

<Input.Root
  value={email}
  onChange={setEmail}
  invalidType={invalidType}
  errorMessage={{
    required: 'Email is required',
    email: 'Enter a valid email address',
  }}
>
  <Input.Label>Email</Input.Label>
  <Input.Field type="email" />
  <Input.Error />
</Input.Root>
```
</ForReact>
<ForVue>
```vue
<script setup>
import { ref } from 'vue'
import { InputRoot, InputField, InputLabel, InputError } from '@wire-ui/vue'

const email = ref('')
const invalidType = ref('')

function handleSubmit(e: Event) {
  e.preventDefault()
  if (!email.value) invalidType.value = 'required'
  else if (!email.value.includes('@')) invalidType.value = 'email'
  else invalidType.value = ''
}
</script>

<template>
  <InputRoot
    v-model="email"
    :invalid-type="invalidType"
    :error-message="{
      required: 'Email is required',
      email: 'Enter a valid email address',
    }"
  >
    <InputLabel>Email</InputLabel>
    <InputField type="email" />
    <InputError />
  </InputRoot>
</template>
```
</ForVue>
