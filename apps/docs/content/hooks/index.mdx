# <ForReact>Hooks</ForReact><ForVue>Composables</ForVue><ForSolid>Primitives</ForSolid>

<ForReact>Wire UI ships a set of small, focused React hooks. They are the same building blocks the components are made from — exported so you can compose your own headless UI with identical behaviour, accessibility, and `data-*` conventions.</ForReact>
<ForVue>Wire UI ships a set of small, focused Vue composables. They are the same building blocks the components are made from — exported so you can compose your own headless UI with identical behaviour, accessibility, and `data-*` conventions.</ForVue>
<ForSolid>Wire UI ships a set of small, focused Solid primitives. They follow Solid's `create*` naming convention and accept reactive option getters. They are the same building blocks the components are made from — exported so you can compose your own headless UI with identical behaviour, accessibility, and `data-*` conventions.</ForSolid>
