# Radio

Single-selection radio group. Controlled via `value` and `onChange`. Items share a `name` attribute for native form semantics.

## Features

<FeatureList>
  <FeatureItem>Single-selection radio group.</FeatureItem>
  <FeatureItem>Full keyboard navigation.</FeatureItem>
  <FeatureItem>Can be controlled or uncontrolled.</FeatureItem>
  <FeatureItem>Shared name attribute for native form semantics.</FeatureItem>
  <FeatureItem>Supports disabled state per item or globally.</FeatureItem>
</FeatureList>

### Basic

<Preview><RadioBasic /></Preview>

```tsx
import { Radio } from '@wire-ui/react'

<Radio.Root name="plan-basic" className="space-y-2">
  {['Startup', 'Business', 'Enterprise'].map((plan) => (
    <Radio.Item
      key={plan}
      value={plan.toLowerCase()}
      className="group relative flex cursor-pointer rounded-[8px] border-2 border-black bg-white px-5 py-4 transition focus:outline-none data-[checked]:bg-[#f5f5f5]">
      <div className="flex w-full items-center gap-3">
        <span className="flex size-5 shrink-0 items-center justify-center rounded-full border-2 border-black bg-white transition group-data-[checked]:bg-black">
          <Radio.Indicator className="size-2 rounded-full bg-white" />
        </span>
        <Radio.Label className="text-sm font-medium text-black">{plan}</Radio.Label>
      </div>
    </Radio.Item>
  ))}
</Radio.Root>
```

## Styling

Radio items expose `data-checked` and `data-disabled`. Use the `group` utility in Tailwind to style child elements based on the parent's state.

```tsx
<Radio.Item className="
  group border-2 border-black
  data-[checked]:bg-gray-50
">
  <span className="
    border-2 border-black rounded-full
    group-data-[checked]:bg-black
  ">
    <Radio.Indicator className="size-2 rounded-full bg-white" />
  </span>
  <Radio.Label>Option</Radio.Label>
</Radio.Item>
```

## Using data attributes

Radio.Item sets `data-checked` when selected and `data-disabled` when disabled.

```css
/* Selected item */
[data-checked] { background: #f5f5f5; }

/* Radio dot */
[data-checked] .dot { background: #000; }

/* Disabled */
[data-disabled] { opacity: 0.5; cursor: not-allowed; }
```

## Root props

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string \| number` | — | Controlled selected value |
| `defaultValue` | `string \| number` | — | Initial selected value |
| `onChange` | `(value: string \| number) => void` | — | Called when selection changes |
| `name` | `string` | auto-generated | Shared `name` attribute for all radio inputs |
| `disabled` | `boolean` | `false` | Disables all items |

## Item props

| Prop | Type | Description |
|---|---|---|
| `value` | `string \| number` | The value this item represents |
| `disabled` | `boolean` | Disables this specific item |

## Indicator data attributes

| Attribute | Values |
|---|---|
| `data-state` | `"checked"` / `"unchecked"` |
| `data-disabled` | Present when disabled |

## Keyboard Interactions

| Key | Description |
|---|---|
| <kbd>ArrowDown</kbd> | Moves focus and selection to the next radio item. |
| <kbd>ArrowUp</kbd> | Moves focus and selection to the previous radio item. |
| <kbd>ArrowRight</kbd> | Moves focus and selection to the next radio item. |
| <kbd>ArrowLeft</kbd> | Moves focus and selection to the previous radio item. |
| <kbd>Tab</kbd> | Moves focus to the selected radio item, or the first item if none is selected. |
