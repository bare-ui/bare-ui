# Divider

Horizontal or vertical separator. Decorative by default (`aria-hidden`). Pass `decorative={false}` for a semantic separator.

## Features

<FeatureList>
  <FeatureItem>Supports horizontal and vertical orientation.</FeatureItem>
  <FeatureItem>Decorative by default with aria-hidden.</FeatureItem>
  <FeatureItem>Semantic separator mode with role="separator".</FeatureItem>
</FeatureList>

### Horizontal

<Preview><DividerBasic /></Preview>

```tsx
import { Divider } from '@wire-ui/react'

<div className="flex flex-col gap-3">
  <p className="text-sm text-black">Item one</p>
  <Divider className="h-[2px] w-full bg-black" />
  <p className="text-sm text-black">Item two</p>
  <Divider className="h-[2px] w-full bg-black" />
  <p className="text-sm text-black">Item three</p>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Divider direction |
| `decorative` | `boolean` | `true` | When `true`: `role="none"` + `aria-hidden`. When `false`: `role="separator"` + `aria-orientation` |
| `...rest` | `HTMLAttributes<HTMLDivElement>` | — | Spread onto the element |
