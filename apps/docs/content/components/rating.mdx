# Rating

Star rating component. Hover preview shows the prospective rating before clicking. Supports read-only (non-interactive) and disabled modes.

## Features

<FeatureList>
  <FeatureItem>Hover preview shows prospective rating before clicking.</FeatureItem>
  <FeatureItem>Supports read-only and disabled modes.</FeatureItem>
  <FeatureItem>Can be controlled or uncontrolled.</FeatureItem>
  <FeatureItem>Custom star styling via starClassName prop.</FeatureItem>
</FeatureList>

### Basic

<Preview><RatingBasic /></Preview>

```tsx
import { Rating } from '@wire-ui/react'

<Rating
  defaultValue={3}
  className="flex gap-0.5"
  starClassName="size-6 cursor-pointer text-[#e5e5e5] outline-none transition-colors data-[highlighted]:text-black data-[filled]:text-black hover:scale-110 data-[disabled]:cursor-default data-[disabled]:opacity-50"
/>
```

### With label

<Preview><RatingComposed /></Preview>

```tsx
import { useState } from 'react'
import { Rating } from '@wire-ui/react'

const [value, setValue] = useState(0)
const labels = ['', 'Terrible', 'Bad', 'Okay', 'Good', 'Excellent']

<div className="flex flex-col items-start gap-2">
  <Rating
    value={value}
    onChange={setValue}
    className="flex gap-0.5"
    starClassName="size-6 cursor-pointer text-[#e5e5e5] outline-none transition-colors data-[highlighted]:text-black data-[filled]:text-black hover:scale-110 data-[disabled]:cursor-default data-[disabled]:opacity-50"
  />
  <p className="text-sm text-[#6b7280]">
    {value > 0 ? <span className="font-medium text-black">{labels[value]}</span> : 'Select a rating'}
  </p>
</div>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `number` | — | Controlled rating value |
| `defaultValue` | `number` | `0` | Initial value for uncontrolled use |
| `onChange` | `(value: number) => void` | — | Called when rating changes |
| `max` | `number` | `5` | Total number of stars |
| `readOnly` | `boolean` | `false` | Non-interactive; renders `role="img"` |
| `disabled` | `boolean` | `false` | Disables interaction |

## Star data attributes

| Attribute | When present |
|---|---|
| `data-filled` | This star is at or below the current rating |
| `data-hover` | Mouse is hovering this star (hover preview) |
