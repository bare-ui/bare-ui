# Badge

Numeric count badge. Caps display at `9+` for large counts. Renders nothing when count is `0` or negative.

## Preview

<ComponentPreview code={`
import { Badge } from '@wire-ui/react'

export default function App() {
  return (
    <div className="p-8 flex gap-6 items-center">
      {[0, 1, 3, 9, 12, 99].map(count => (
        <div key={count} className="flex flex-col items-center gap-1">
          <Badge
            count={count}
            className="inline-flex items-center justify-center min-w-5 h-5 px-1.5 rounded-full bg-red-500 text-white text-xs font-bold"
          />
          <span className="text-xs text-gray-400">{count}</span>
        </div>
      ))}
    </div>
  )
}
`} height={100} />

## Usage

```tsx
import { Badge } from '@wire-ui/react'

<Badge count={3} />   // renders "3"
<Badge count={12} />  // renders "9+"
<Badge count={0} />   // renders nothing
```

## Props

| Prop | Type | Description |
|---|---|---|
| `count` | `number` | The count to display |
| `...rest` | `HTMLAttributes<HTMLSpanElement>` | Spread onto the `<span>` |

## Data attributes

| Attribute | Description |
|---|---|
| `data-count` | The raw numeric value (always present, even when `9+` is displayed) |
